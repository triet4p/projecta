# Ontology migration: v0.1.0 → v0.2.0

**Status:** HUMAN_APPROVED
**Classification:** no-op, additive minor-version compatibility artifact

## Scope

No existing v0.1 IRI, triple, named graph, query result, or dataset requires a
rewrite. v0.2 adds lifecycle vocabulary, SHACL shapes, and the five-graph
contract without renaming, deleting, or changing the meaning of v0.1 terms.

## Migration action

Do not transform v0.1 data. Keep existing source data unchanged, load the v0.2
ontology modules and shapes beside it, then validate with the canonical command:

```text
docker compose run --build --rm ontology-test
```

New lifecycle data must use the graph IRI templates in
`docs/ontology/named-graph-contract.md`. This is a forward-authoring rule, not
a migration of existing data.

## Verification and rollback

The suite retains all 32 v0.1 regression checks. A failed validation blocks
adoption of the v0.2 modules; rollback consists of removing the v0.2 modules
and shapes from the consuming deployment. No RDF data rollback is required
because this migration makes no data mutation.
