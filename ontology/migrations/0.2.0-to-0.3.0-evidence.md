# Ontology migration: v0.2.0 → v0.3.0

**Status:** HUMAN_APPROVED
**Classification:** additive minor-version release

The release adds `rawText`, `evidenceStartOffset`, and `evidenceEndOffset` for
new M2 source records. Existing v0.1/v0.2 Notes remain valid under their
released shapes and require no backfill. Runtime candidate validation selects
the shape set from `projecta:proposedOntologyVersion`: exactly `0.1.0` and
`0.2.0` use the released candidate/source shapes; every other version, including
malformed, unknown, and future versions, uses the strict current shapes. New M2 capture always proposes `0.3.0` and must
validate against the evidence shapes before commit. The compatibility fixture
`quick-note-v02-legacy-candidate.trig` and the remote lifecycle regression
prove that a legacy v0.2 candidate can still validate and confirm without the
new evidence fields. Rollback removes the v0.3 module and M2 data created
against it from an isolated local test dataset. Release approval was recorded
on 2026-08-01; no shared or production dataset was changed.
